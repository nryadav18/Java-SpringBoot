# Topic 3 - Control Flow

Decisions (`if`, `else if`, ternary, classic and arrow `switch`, switch expressions with `yield`)
and repetition (`for`, `while`, `do-while`, for-each, `break`/`continue`, labels, nested loops).
Open `lesson.html` in a browser for the full lesson.

## Files
| File | What it shows |
|------|---------------|
| `lesson.html` | The full lesson (start here) |
| `Example01_IfElse.java` | if/else, grade ladder, nested if, leap year, ternary |
| `Example02_Switch.java` | Classic switch, fall-through, arrow switch, switch expressions, `yield` |
| `Example03_Loops.java` | for, while, do-while, enhanced for |
| `Example04_BreakContinueLabels.java` | break, continue, labelled break and continue |
| `Example05_NestedLoopsPatterns.java` | Star and number patterns with nested loops |
| `Example06_CommonLoopProblems.java` | Sum, factorial, prime, FizzBuzz, table, reverse, Fibonacci |
| `Example07_AtmMenu.java` | Mini-program: ATM with PIN check and menu (reads input, PIN 1234) |

## How to run
Open a terminal in this folder and run any example, e.g.:

```
java Example02_Switch.java
java Example07_AtmMenu.java
```

Each non-interactive file shows its expected output in a comment at the bottom.
