# Topic 4 - Methods & Arrays

Methods (parameters, return values, overloading, varargs, pass-by-value, recursion, scope)
and arrays (1D, 2D, jagged, the `Arrays` utility class, classic algorithms).
Open `lesson.html` in a browser for the full lesson.

## Files
| File | What it shows |
|------|---------------|
| `lesson.html` | The full lesson (start here) |
| `Example01_MethodBasics.java` | void vs return methods, parameters vs arguments, guard clauses |
| `Example02_OverloadingAndVarargs.java` | Overloaded `area`/`printReceipt`, varargs `sum(int...)` |
| `Example03_PassByValue.java` | Primitive copy vs shared array reference |
| `Example04_Recursion.java` | Countdown, factorial (traced), Fibonacci and its cost, digit sum |
| `Example05_Scope.java` | Field, parameter, local, block and loop scope; shadowing |
| `Example06_ArrayBasics.java` | Creating, reading, looping arrays; defaults; references |
| `Example07_TwoDimensionalArrays.java` | Marks table, row/column totals, jagged arrays, transpose |
| `Example08_ArraysUtilityClass.java` | sort, toString, fill, copyOf, copyOfRange, binarySearch, equals |
| `Example09_ArrayAlgorithms.java` | max/min, reverse, linear & binary search, bubble sort |
| `Example10_StudentMarksReport.java` | Mini-program: formatted student marks report |

## How to run
Open a terminal in this folder and run any example, e.g.:

```
java Example04_Recursion.java
java Example10_StudentMarksReport.java
```

Each file shows its expected output in a comment at the bottom.
