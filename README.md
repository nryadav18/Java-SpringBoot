# Java + Spring Boot: From Zero to Enterprise

**Open `index.html` in your browser first.** It is the course home page, with the roadmap, study plan, pros and cons, and links to all 71 topics.

- 71 topic folders (`1-Introduction-And-Setup` … `71-Capstone-Project-ECommerce-Backend`), to be done in order.
- Each folder has `lesson.html` (the full explanation), `README.md` (quick summary and how to run), and runnable code.
- Stack: Java 17, Spring Boot 3.5.6, Maven, H2 then MySQL, Docker. Editor: VS Code.
