# Topic 2 - Variables, Data Types & Operators

Variables, the 8 primitive types, String intro, type casting, `var`, constants (`final`),
all the everyday operators, precedence, the Math class, wrapper classes and autoboxing.
Open `lesson.html` in a browser for the full lesson.

## Files
| File | What it shows |
|------|---------------|
| `lesson.html` | The full lesson (start here) |
| `Example01_Variables.java` | Declare, assign, change variables; naming rules |
| `Example02_PrimitiveTypes.java` | All 8 primitives, ranges, literal suffixes, the 0.1 + 0.2 surprise |
| `Example03_TypeCastingVarAndConstants.java` | Widening, narrowing, overflow, parseInt, `var`, `final` |
| `Example04_Operators.java` | Arithmetic, integer division, modulo, ++/--, comparison, logical, precedence |
| `Example05_MathAndWrapperClasses.java` | Math methods, wrappers, autoboxing, `==` vs `equals` |
| `Example06_ShoppingBillCalculator.java` | Mini-program: formatted bill with discount and GST |
| `Example07_TemperatureConverter.java` | Mini-program: Celsius to Fahrenheit/Kelvin (reads input) |

## How to run
Open a terminal in this folder and run any example, e.g.:

```
java Example01_Variables.java
java Example06_ShoppingBillCalculator.java
```

Each file shows its expected output in a comment at the bottom.
