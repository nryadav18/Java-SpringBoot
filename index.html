1. Where to start (read this first)

👉 Your first click Start with Topic 1 · Introduction & Setup and go in order. Every lesson assumes you have finished the ones before it, and nothing assumes knowledge from a later one.

You told me you are starting from zero. Here is the honest truth from ten years of teaching: beginners usually struggle with Spring Boot because they skipped Core Java, not because Spring is hard. Spring is full of interfaces, annotations, generics, lambdas and collections. If those feel natural, Spring feels easy. That is why Part A (Core Java) is 21 topics long. Don't rush it.

1️⃣ Read the lesson
Open lesson.html in the topic folder. Read it top to bottom, including the analogy.
2️⃣ Run the code
Open the same folder in VS Code. Run every example and compare the output with the lesson.
3️⃣ Break the code
Change values, delete lines, cause errors on purpose. That is how real understanding happens.
4️⃣ Practise
Do the exercises before opening the solutions. Then answer the interview questions out loud.

2. What are Java, Spring and Spring Boot?

🏠 Think of building a house
  • Java is the bricks, cement and tools: the language you build with.
  • Spring Framework is a set of ready-made building systems: plumbing, wiring and doors that fit together. You don't invent them yourself.
  • Spring Boot is a builder who arrives with all of that already assembled and configured. You say "I want a web app with a database" and the foundation is ready in minutes.
Your code→ Spring Boot
auto-config, starters, embedded server→ Spring Framework
IoC, DI, MVC, Data, Security…→ Java + JVM
JavaSpring FrameworkSpring Boot
What it isA programming language plus the JVM runtimeA framework that manages your objects (beans) and gives you web, data and security modulesA layer on top of Spring that removes setup work
You writeClasses, methods, logicClasses plus configurationMostly business logic. The configuration is automatic.
Runs asjava MyAppUsually deployed into a server such as TomcatOne runnable .jar with the server inside: java -jar app.jar

3. Advantages and disadvantages

Why Java + Spring Boot? (Advantages)

AdvantageWhat it means for you
🚀 Fast startAuto-configuration and "starters" give you a working REST API in about 10 lines of code.
🏢 Enterprise standardBanks, insurance, telecom, e-commerce and government systems run on it. Job demand is very high and steady.
🧩 Huge ecosystemSpring Data, Security, Cloud, Batch, Kafka, GraphQL and more all work together with the same style.
📦 Embedded serverTomcat is inside your jar, so there is no separate server to install. This is ideal for Docker and the cloud.
🧪 TestabilityDependency Injection makes it easy to swap real parts for fakes in tests. Excellent built-in test support.
🔒 Security built inSpring Security is battle-tested for login, roles, JWT and OAuth2.
📊 Production-readyActuator gives health checks, metrics and monitoring for free.
☕ Java's strengthsStrong typing catches mistakes early, the JVM is very fast at scale, and backward compatibility is excellent.
👥 CommunityMillions of developers, so almost every error message you hit has an answer online.

Honest disadvantages (and how this course handles them)

DisadvantageHow we deal with it
🎩 "Magic": a lot happens automatically, which can confuse beginnersTopic 18 builds a mini Spring by hand, and topics 22–27 teach plain Spring before Boot, so the magic is understood rather than memorised.
📚 Big learning curve: many modules and annotationsOne concept per topic, always in order, always with a runnable example.
🐢 Slower startup and higher memory than Go or Node.jsFine for most business apps. We cover tuning, and GraalVM native images are mentioned as a next step.
✍️ Java is wordier than Python or KotlinModern Java (records, var, lambdas, streams, topic 15) removes most boilerplate.
🧱 Easy to over-engineer, for example microservices too earlyTopic 59 explains when not to use microservices. Topic 70 teaches clean, simple design.
🔄 Frequent versions (Boot 2 → 3 → 4)We use Spring Boot 3.5 on Java 17, the most widely used setup in companies today. The concepts carry over directly to Boot 4.

7. One-time setup

Good news: your machine already has Java 17 (Temurin), Maven 3.9 and Docker. Topic 1 walks through verifying them. In VS Code, install these extensions:

ExtensionWhy
Extension Pack for Java (Microsoft)Run and debug Java, IntelliSense, Maven support
Spring Boot Extension Pack (VMware/Broadcom)Spring Initializr, Boot Dashboard, properties autocomplete
REST Client (Huachao Mao)Run the requests.http files to call your APIs
Docker (Microsoft)Manage containers for MySQL, Redis, Kafka and more (from topic 43)
java -version     # should print 17.x
mvn -v            # should print Apache Maven 3.9.x
docker --version  # needed from topic 43 onwards
ℹ️ DatabasesUntil topic 42 every example uses H2, an in-memory database that needs no installation. Topic 43 shows how to switch to MySQL running in Docker. Kafka, RabbitMQ, Redis and Zipkin also run with one docker compose up -d command each.

11. How to learn effectively

⌨️ Type, don't copy
Retype the examples yourself. Your fingers learn syntax faster than your eyes.
🐞 Love errors
Read the whole error message, especially the first "Caused by" line. Most answers are there.
🔁 Revise
Every weekend, re-read the "Key takeaways" of the week's topics and answer the interview questions.
🧠 Explain it
If you can explain a topic to a friend in two minutes, you have learned it.
🛠️ Build a side project
After topic 42, start your own small app, such as a library or expense tracker, and grow it with each topic.
📁 Use Git
Commit your exercise solutions to GitHub. Topic 68 covers Git basics. Recruiters look at GitHub.
⚠️ The #1 beginner trapWatching or reading without coding. Every lesson has runnable code and exercises. If you didn't run it, you didn't learn it.
